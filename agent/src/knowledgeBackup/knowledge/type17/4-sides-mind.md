### The Four Sides of the Mind

| Mind Aspect        | Gateway Function      | Development Goal                           |
| ------------------ | --------------------- | ------------------------------------------ |
| Ego                | Hero Function (1)     | Confident application                      |
| Subconscious       | Inferior Function (4) | Balance and happiness                      |
| Shadow/Unconscious | Nemesis Function (5)  | Integration of repressed unconscious parts |
| Superego           | Demon Function (8)    | Enlightened mastery                        |
