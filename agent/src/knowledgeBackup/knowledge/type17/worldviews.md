# Types Worldviews

### **Concrete vs Abstract**

| **Category**          | **Concrete**                                                                                               | **Abstract**                                                                                                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Definition**        | Focuses on **tangibles** (physical world, experiences). Observes via senses.                               | Focuses on **intangibles** (concepts, implications, hidden meanings). Perceives through intuition.                                |
| **Prone To**          | Skepticism, tunnel-vision, hyper-focus on details.                                                         | Impracticality, wild speculation, entertaining unlikely possibilities.                                                            |
| **Aims To**           | Earn experiences, be practical, calibrate expectations.                                                    | Anticipate, theorize, visualize, imagine, find hidden meanings.                                                                   |
| **Exhibits**          | Sensibility, empiricism, realism, seeing things as they are.                                               | Vision, idealism, prescience, future-orientation.                                                                                 |
| **Example Scenarios** | _“How about we talk about what does exist instead.”_ <br> _“A bird in the hand is worth two in the bush.”_ | _“Imagine if the dinosaurs were still alive.”_ <br> _“So many things are possible as long as you don’t know they’re impossible.”_ |

---

### **Affiliative vs Pragmatic**

| **Category**          | **Affiliative**                                                                                     | **Pragmatic**                                                                                           |
| --------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Definition**        | Focuses on **group standards** (“what’s right”). Values cooperation and authority.                  | Focuses on **individual effectiveness** (“what works”). Challenges authority and seeks independence.    |
| **Prone To**          | Peer pressure, enforcing norms, suppressing dissent.                                                | Rebellion, antagonism, contrarianism, disobedience.                                                     |
| **Aims To**           | Harmonize, build unity, establish consensus, mediate.                                               | Distinguish, self-rule, optimize, maximize personal opportunity.                                        |
| **Exhibits**          | Interconnection, openness, inclusion, teamwork, asking permission.                                  | Operational structure, challenge, improvement, achieving personal goals.                                |
| **Example Scenarios** | _“Teamwork makes the dream work.”_ <br> _“We need to work together or we’ll undermine each other.”_ | _“If you want something done right, do it yourself.”_ <br> _“Self-sufficiency is key to self-respect.”_ |

---

### **Systematic vs Interest**

| **Category**          | **Systematic**                                                                         | **Interest**                                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Definition**        | Seeks the **best process/method** for predictable results. Objective focus.            | Seeks **who benefits** (win-win or win-lose outcomes). Subjective focus.                                         |
| **Prone To**          | Overanalysis, insensitivity, process-over-people mentality.                            | Moving goalposts, favoritism, improvisation, shrewdness.                                                         |
| **Aims To**           | Build frameworks, classify, streamline, find the "best way."                           | Negotiate, barter, review, haggle, find what people want.                                                        |
| **Exhibits**          | Standardization, meticulous effort, development of techniques.                         | Improvisation, careful appraisal, persuasiveness, agenda-driven actions.                                         |
| **Example Scenarios** | _“Trust the process we prepared.”_ <br> _“Methodically build a routine for your day.”_ | _“Everybody wants something—find their price.”_ <br> _“It’s about everyone getting a little of what they want.”_ |

**Worldview Matrix 🌍**:
| Combination | Type Group | Core Orientation |
|----------------------|-----------------|------------------|
| Concrete+Affiliative+Systematic | SJ (Guardians) 🧑‍🚒 | Stability through collective responsibility |
| Concrete+Pragmatic+Interest | SP (Artisans) 🧑‍🏭 | Impact through immediate action |
| Abstract+Pragmatic+Systematic | NT (Intellectuals) 🧠 | Progress through systems mastery |
| Abstract+Affiliative+Interest | NF (Idealists) 💡 | Growth through shared values |
