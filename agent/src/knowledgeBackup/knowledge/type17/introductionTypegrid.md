# The Type Grid System

## Introduction to TypeGrid

A matrix-based personality assessment tool combining Jungian psychology with modern behavioral analysis. Unlike traditional binary tests, it uses **elimination methodology** across two axes:

1. **Worldview** (Cognitive Filters):
   How you process information (SJ/SP/NT/NF)

2. **Expression Style** (Behavioral Patterns):
   How you interact with the world (Structure/Starter/Finisher/Background)

Key Features:

- 75%+ consistency rate vs standard MBTI's tests 50%
- Focus on observable behaviors over self-reported traits
- Accounts for developmental stages of the 4 sides of the mind (Ego/Subconscious/Unconscious/Superego)
- Based on the 8-function model of John Beebe
